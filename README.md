# هدية فاطمة — نسخة جاهزة للربط والنشر

هذه حزمة مشروع (وليست رابطًا منشورًا بعد). واجهة عربية فاخرة، ظرف متحرك، عداد، معرض صور، خط زمني، مفاجأة وأغنية. تعتمد البيانات والصور على Supabase، والتعديل يمر عبر Edge Function محمية بسر موجود على الخادم.

## الحسابات المطلوبة
1. **Supabase**: تم ربط ملفات الواجهة بمشروعك الحالي `poorxeaqtpagudizhosl`، لكن يجب تنفيذ SQL ونشر دالة الإدارة.
2. **Render**: حساب مجاني لنشر الواجهة من https://render.com
3. **GitHub** (الأسهل للنشر المستمر): حساب من https://github.com، ارفع إليه ملفات المشروع واربط المستودع بـ Render. يمكنك بدلًا من ذلك نشر ملفات الواجهة يدويًا، لكن GitHub أسهل للتحديثات.

## 1) إعداد Supabase
- افتح مشروعك ثم SQL Editor، والصق وشغّل `supabase/setup.sql`.
- رابط المشروع والمفتاح العام ورابط الدالة تم وضعهم مسبقًا في `index.html` لمشروعك الحالي. إذا غيّرت المفتاح العام مستقبلًا، حدّث `SUPABASE_ANON_KEY` فقط. المفتاح الموجود في الواجهة هو publishable key وليس مفتاحًا سريًا.
- المفتاح العام (anon/publishable) مسموح في الواجهة مع سياسات RLS. **لا تضع service_role key أو ADMIN_SECRET داخل index.html أو GitHub.**

## 2) نشر دالة الإدارة الآمنة
تحتاج Supabase CLI مثبتًا على كمبيوتر (أو بيئة تطوير تدعم CLI) ثم من مجلد المشروع:
1. `supabase login`
2. `supabase link --project-ref poorxeaqtpagudizhosl`
3. أنشئ سرًا عشوائيًا طويلًا (32+ حرفًا) واحتفظ به. لا تستخدم كلمة مرور قصيرة.
4. `supabase secrets set ADMIN_SECRET="YOUR_LONG_RANDOM_SECRET"`
5. `supabase functions deploy admin --no-verify-jwt`

ستستخدم الدالة `SUPABASE_SERVICE_ROLE_KEY` و`SUPABASE_URL` من بيئة Supabase تلقائيًا. لا تشارك السر مع أي شخص.

## 3) رابط الإدارة
رابط الهدية يكون مثل:
`https://YOUR-SITE.onrender.com/` (استبدل المثال بالرابط الذي يمنحك إياه Render)
رابط الإدارة يكون مثل:
`https://YOUR-SITE.onrender.com/?manage=1&key=YOUR_LONG_RANDOM_SECRET`
احتفظ برابط الإدارة في مدير كلمات المرور ولا ترسله إلى فاطمة. لأن السر موجود في عنوان URL، لا تفتحه على جهاز عام ولا ترسله في صور/لقطات شاشة. يمكن استبداله في أي وقت بتغيير `ADMIN_SECRET` وإعادة فتح رابط جديد. حماية الخادم تتحقق من السر؛ مجرد إظهار زر الإدارة لا يمنح صلاحية دون السر الصحيح.

## 4) نشر الواجهة على Render
- ارفع محتويات هذا المجلد إلى GitHub repository.
- في Render اختر New → Static Site ثم اربط المستودع.
- Publish Directory: `.` (النقطة)، وBuild Command اتركه فارغًا.
- بعد النشر ستحصل على رابط `onrender.com` مع HTTPS. افتح الرابط وتأكد أن الصفحة تقرأ بيانات `fatma` من Supabase.
- لا تحتاج نطاقًا مدفوعًا؛ نطاق Render المجاني يكفي.

## ملاحظات
- روابط الصور عامة لأن صور الهدية تظهر لأي شخص معه رابط الصفحة؛ لا ترفع صورًا لا تريد أن تكون قابلة للمشاهدة.
- الأغنية: ضع رابطًا مباشرًا لملف صوتي مسموح لك باستخدامه. روابط Spotify/YouTube ليست روابط MP3 مباشرة غالبًا، وقد تمنع التشغيل داخل مشغل الصفحة.
- Free tiers مناسبة للتجربة/الهدية الصغيرة، لكن لها حدود استخدام وقد تتغير. راجع صفحة الأسعار الحالية قبل الاستخدام طويل المدى.
- النسخة الحالية تستخدم سرًا في query string. هذا عملي لمشروع شخصي صغير لكنه أقل أمانًا من تسجيل دخول حقيقي؛ إذا احتجت حماية أقوى فالأفضل Supabase Auth.
